# Human Writing System - Landing Page

This repository contains the landing page for the **Human Writing System**, a premium system designed to help you stop sounding like an AI and start writing with true human impact.

## 🚀 Features
- **Modern Premium Design**: Dark luxury aesthetic utilizing a deep `#030303` base.
- **Glassmorphism**: Elegant frosted cards with subtle inner glow and motion blur.
- **Dynamic Scroll Animations**: Uses modern `IntersectionObserver` to reveal content dynamically as you scroll smoothly down the page.
- **Ambient Glows**: Atmospheric drifting background glows created instantly with CSS.

## 🛠️ Built With
- Pure HTML5 
- Vanilla CSS3

## 💻 Getting Started
To view the site locally, simply clone this repository and open `index.html` in your favorite modern browser:

```bash
git clone <your-repo-link>
cd <your-repo-folder>
```
Open `index.html` directly to witness the animations and premium layout.
